## What moved

Use [Build your own login and signup UI](/docs/guides/custom-login-ui) for the complete implementation:

1. configure `UseHeadlessAuthPage(...)` and `BuildUiUrl`;
2. keep credentialed browser calls on a supported same-site/CORS boundary;
3. start `/authorize` with client state and S256 PKCE;
4. render the server-owned identify, credential, organization, and MFA views;
5. validate callback state and exchange the code with the original verifier;
6. add product-owned signup fields without taking over identity state.

This URL remains as a compatibility entry point for existing links. It is intentionally not a second copy of the walkthrough.
