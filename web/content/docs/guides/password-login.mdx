You'll learn how to register SqlOS, seed an owned client, and sign in through the hosted login UI.

<Callout type="info" title="Prerequisites">
  - Completed [Getting Started](/docs/getting-started)
  - SQL Server connection string configured
  - A `DbContext` implementing `ISqlOSAuthServerDbContext`
</Callout>

## Goal

Users sign in at `/sqlos/auth/login` with email and password. Your app uses the OAuth authorization code flow with PKCE.

![Hosted AuthPage showing the password credential step](/docs/guides-password-login.png)

This screenshot comes from the Todo demo with `EnabledCredentialTypes = ["password"]`. SqlOS asks for the email first so it can perform home realm discovery, then shows the password step above when local password auth is the only configured primary credential.

## Steps

1. **Register SqlOS** with password auth enabled (default):

```csharp
builder.AddSqlOS<AppDbContext>(options =>
{
    options.AuthServer.SeedOwnedWebApp(
        "web",
        "My App",
        "https://localhost:5001/auth/callback");
    options.AuthServer.SeedAuthPage(page =>
    {
        page.PageTitle = "Sign in";
        page.EnablePasswordSignup = true;
        page.EnabledCredentialTypes = ["password"];
    });
});
```

2. **Map routes** after `Build()`:

```csharp
app.MapSqlOS();
```

3. **Start the app** and open `/sqlos/auth/authorize` with your client id, redirect URI, and PKCE challenge (the Todo sample shows a full flow).

4. **Verify**: complete login and confirm your app receives tokens at the callback URL.

## Expected outcome

- Hosted login and signup pages render with your branding
- OAuth `/authorize` and `/token` endpoints respond on your origin
- Users and sessions appear in `/sqlos/admin/auth/`
