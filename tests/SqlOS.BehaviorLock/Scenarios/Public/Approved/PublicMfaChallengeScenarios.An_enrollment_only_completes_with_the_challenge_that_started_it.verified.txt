## 4. client: the first enrollment with the second challenge is refused, even with the right code
> POST /sqlos/auth/mfa/challenge/totp/enroll/verify
> Content-Type: application/json; charset=utf-8
>   {
>     "code": "{code#1}",
>     "enrollmentToken": "{enrollment-token#1}",
>     "mfaToken": "{mfa-token#2}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    "MFA enrollment is not authorized for this challenge."

## 5. client: without its challenge, a challenge-bound enrollment is refused too

>     "enrollmentToken": "{enrollment-token#1}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    "Challenge-bound enrollment must be verified with its original MFA challenge."
