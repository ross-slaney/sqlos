## 2. client: the public refresh route carries no client credentials, so it refuses the confidential client's token
> POST /sqlos/auth/token/refresh
> Content-Type: application/json; charset=utf-8
>   {
>     "refreshToken": "{refresh-token#1}"
>   }
< 401 Unauthorized
< Content-Type: application/json; charset=utf-8
    {
      "error": "invalid_client",
      "error_description": "Client authentication failed."
    }
