# Known defect (found by this catalog, not yet filed): after the pick, SqlOS issues the code and signs the browser in, then re-reads the now-completed authorization request and answers 400, so the code is never delivered. With an MFA policy the pick continues to the challenge instead (HeadlessMfaScenarios).
