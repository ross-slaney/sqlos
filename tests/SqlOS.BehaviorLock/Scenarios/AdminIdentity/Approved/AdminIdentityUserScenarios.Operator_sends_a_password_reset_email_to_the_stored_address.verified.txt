## 5. operator: plain HTTP to another host is rejected and the send is audited as failed
> POST /sqlos/admin/auth/api/users/{usr#2}/password-reset-email
> Content-Type: application/json; charset=utf-8
> X-BehaviorLock-Operator: behavior-lock-operator
>   {
>     "resetUrlTemplate": "http://app.example.test/reset?token={token}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "message": "The configured password reset URL must be an absolute HTTPS URL (or loopback HTTP URL) without user information."
    }

## 6. operator: the token may not appear in the URL authority
> POST /sqlos/admin/auth/api/users/{usr#2}/password-reset-email
> Content-Type: application/json; charset=utf-8
> X-BehaviorLock-Operator: behavior-lock-operator
>   {
>     "resetUrlTemplate": "https://{token}.example.test/reset"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "message": "The password reset token placeholder cannot appear in the URL authority."
    }

## 7. operator: nor may the URL carry user information
> POST /sqlos/admin/auth/api/users/{usr#2}/password-reset-email
> Content-Type: application/json; charset=utf-8
> X-BehaviorLock-Operator: behavior-lock-operator
>   {
>     "resetUrlTemplate": "https://user:pass@app.example.test/reset?token={token}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "message": "The configured password reset URL must be an absolute HTTPS URL (or loopback HTTP URL) without user information."
    }

## 8. operator: a user without a password cannot be sent a reset
