scenario: ScimOwnershipScenarios.A_directory_cannot_write_an_email_outside_the_organizations_verified_domains
profile: enterprise-scim-path

## 1. directory: provisioning an address at a domain Acme has not verified is rejected
> POST /scim/v2/Users
> Authorization: Bearer {scim-token#1}
> Content-Type: application/scim+json; charset=utf-8
>   {
>     "active": true,
>     "emails": [
>       {
>         "primary": true,
>         "type": "work",
>         "value": "{email:victim}"
>       }
>     ],
>     "externalId": "directory-victim",
>     "name": {
>       "familyName": "Tim",
>       "givenName": "Vic"
>     },
>     "schemas": [
>       "urn:ietf:params:scim:schemas:core:2.0:User"
>     ],
>     "userName": "{email:victim}"
>   }
< 400 Bad Request
< Content-Type: application/scim+json
    {
      "detail": "SCIM email domain is not verified for this organization.",
      "schemas": [
        "urn:ietf:params:scim:api:messages:2.0:Error"
      ],
      "scimType": "invalidValue",
      "status": "400"
    }
