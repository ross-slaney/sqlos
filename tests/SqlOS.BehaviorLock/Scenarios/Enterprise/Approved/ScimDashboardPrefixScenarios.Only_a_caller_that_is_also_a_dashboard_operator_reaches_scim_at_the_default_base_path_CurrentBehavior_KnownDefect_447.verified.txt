# SqlOS behavior lock transcript
scenario: ScimDashboardPrefixScenarios.Only_a_caller_that_is_also_a_dashboard_operator_reaches_scim_at_the_default_base_path_CurrentBehavior_KnownDefect_447
profile: enterprise

# The operator actor carries the dashboard's AuthorizationCallback header; a directory never would.

## 1. operator: with the operator header but no SCIM token, the request reaches SCIM, which demands its own token
> GET /sqlos/scim/v2/ServiceProviderConfig
> X-BehaviorLock-Operator: behavior-lock-operator
< 401 Unauthorized
< Content-Type: application/scim+json
< Referrer-Policy: same-origin
< WWW-Authenticate: Bearer realm="SqlOS SCIM"
< X-Content-Type-Options: nosniff
< X-Frame-Options: DENY
    {
      "detail": "SCIM bearer token is required.",
      "schemas": [
        "urn:ietf:params:scim:api:messages:2.0:Error"
      ],
      "status": "401"
    }
