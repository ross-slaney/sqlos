# SqlOS behavior lock transcript
scenario: AuthLibraryScenarios.Third_party_clients_cannot_sign_users_in_directly
profile: hosted

## 1. probe: password sign-in for a third-party client is refused
> POST /__probe/auth/password-login
> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "partner-app",
>     "email": "{email:alice}",
>     "password": "{password:alice}"
>   }
< 422 Unprocessable Entity
< Content-Type: application/json; charset=utf-8
    {
      "error": "SqlOSPublicAuthException",
      "message": "This client must use the authorization endpoint to sign users in."
    }
