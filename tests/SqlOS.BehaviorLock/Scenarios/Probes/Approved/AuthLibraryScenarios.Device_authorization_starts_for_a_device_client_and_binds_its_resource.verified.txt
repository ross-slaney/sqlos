## 3. probe: any other resource is refused as invalid_target
> POST /__probe/auth/device-authorization
> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "atlas-cli",
>     "resource": "https://billing.example.test",
>     "scope": "openid"
>   }
< 422 Unprocessable Entity
< Content-Type: application/json; charset=utf-8
    {
      "error": "SqlOSDeviceAuthorizationException",
      "message": "Requested resource is not allowed for this client."
    }

## 4. probe: a client without the device grant is refused
> POST /__probe/auth/device-authorization
> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "atlas-portal",
>     "scope": "openid"
>   }
< 422 Unprocessable Entity
< Content-Type: application/json; charset=utf-8
    {
      "error": "SqlOSDeviceAuthorizationException",
      "message": "This client is not allowed to use device authorization."
    }

## 5. probe: an unknown client is refused
> POST /__probe/auth/device-authorization
> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "no-such-client",
>     "scope": "openid"
>   }
< 422 Unprocessable Entity
< Content-Type: application/json; charset=utf-8
    {
      "error": "InvalidOperationException",
      "message": "Unknown client 'no-such-client'."
    }
