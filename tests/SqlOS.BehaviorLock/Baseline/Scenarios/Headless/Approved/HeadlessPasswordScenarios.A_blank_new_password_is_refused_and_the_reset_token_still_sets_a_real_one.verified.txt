# SqlOS behavior lock transcript
scenario: HeadlessPasswordScenarios.A_blank_new_password_is_refused_and_the_reset_token_still_sets_a_real_one
profile: headless

## 1. browser: an empty new password is refused, and the token is not spent (7.2.1 stored it)
> POST /sqlos/auth/headless/password/reset
> Content-Type: application/json; charset=utf-8
> Origin: https://sqlos.example.test
>   {
>     "newPassword": "",
>     "token": "{link-token#1}"
>   }
< 204 No Content

## 2. browser: so is a blank one
> POST /sqlos/auth/headless/password/reset
> Content-Type: application/json; charset=utf-8
> Origin: https://sqlos.example.test
>   {
>     "newPassword": "   ",
>     "token": "{link-token#1}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "error": "invalid_request",
      "message": "Password reset token is invalid or expired."
    }

## 3. browser: the same token then sets a real password
> POST /sqlos/auth/headless/password/reset
> Content-Type: application/json; charset=utf-8
> Origin: https://sqlos.example.test
>   {
>     "newPassword": "{password:alice-new}",
>     "token": "{link-token#1}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "error": "invalid_request",
      "message": "Password reset token is invalid or expired."
    }

## 4. browser: an empty password does not sign in
> POST /sqlos/auth/headless/password/login
> Content-Type: application/json; charset=utf-8
> Origin: https://sqlos.example.test
>   {
>     "email": "{email:alice}",
>     "password": "",
>     "requestId": "{req#1}"
>   }
< 200 OK
< Content-Type: application/json; charset=utf-8
< Set-Cookie: sqlos_auth_page={cookie#1}; expires=+7d; path=/; secure; samesite=lax; httponly
    {
      "redirectUrl": "https://sqlos.example.test/auth/callback?code={code#1}&state={state#1}&scope=openid%20profile%20email%20offline_access",
      "type": "redirect",
      "viewModel": null
    }

## 5. browser: the new password signs in
> POST /sqlos/auth/headless/password/login
> Content-Type: application/json; charset=utf-8
> Cookie: sqlos_auth_page={cookie#1}
> Origin: https://sqlos.example.test
>   {
>     "email": "{email:alice}",
>     "password": "{password:alice-new}",
>     "requestId": "{req#1}"
>   }
< 400 Bad Request
< Content-Type: application/json; charset=utf-8
    {
      "error": "invalid_request",
      "message": "Authorization request is invalid or expired."
    }
