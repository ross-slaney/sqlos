> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "behavior-lock-app",
>     "email": "{email:nopass}",
>     "password": "{password:pat}"
>   }
< 500 Internal Server Error
< X-BehaviorLock-Unhandled-Exception: System.InvalidOperationException: Invalid email or password.
