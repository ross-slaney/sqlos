# SqlOS behavior lock transcript
scenario: AdminIdentityUserScenarios.Admin_reads_return_database_timestamps_without_a_utc_marker_CurrentBehavior_KnownDefect_325
profile: dashboard-callback

# Known defect #325, recorded as it behaves today: create responses serialize the in-memory UTC value with Z, while every value read back from the database has no zone ({datetime:unspecified}).

## 1. operator: the create response carries Z
> POST /sqlos/admin/auth/api/users
> Content-Type: application/json; charset=utf-8
> X-BehaviorLock-Operator: behavior-lock-operator
>   {
>     "displayName": "Alice",
>     "email": "{email:alice}"
>   }
< 200 OK
< Content-Type: application/json; charset=utf-8
    {
      "createdAt": "{datetime:utc-z}",
      "defaultEmail": "{email:alice}",
      "displayName": "Alice",
      "id": "{usr#1}",
      "isActive": true,
      "updatedAt": "{datetime:utc-z}"
    }
