## 2. app-backend: clientId may name the token's client
> POST /sqlos/auth/token/refresh
> Content-Type: application/json; charset=utf-8
>   {
>     "clientId": "behavior-lock-app",
>     "refreshToken": "{refresh-token#2}"
>   }
< 200 OK
< Content-Type: application/json; charset=utf-8
    {
      "accessToken": "{access-token#1}",
      "accessTokenExpiresAt": "{datetime:utc-z}",
      "clientId": "behavior-lock-app",
      "idToken": "{id-token#1}",
      "organizationId": null,
      "refreshToken": "{refresh-token#3}",
      "refreshTokenExpiresAt": "{datetime:utc-z}",
      "sessionId": "{ses#1}"
    }

# an unknown refresh token: SqlOS throws System.InvalidOperationException "Refresh token is invalid." and writes no response (Kestrel answers 500).

# no refresh token: SqlOS throws System.ArgumentNullException "Value cannot be null. (Parameter 's')" and writes no response (Kestrel answers 500).

# a clientId that did not receive the token: SqlOS throws System.InvalidOperationException "Refresh token was not issued for this client." and writes no response (Kestrel answers 500).

## 3. app-backend: malformed JSON is refused by the framework
