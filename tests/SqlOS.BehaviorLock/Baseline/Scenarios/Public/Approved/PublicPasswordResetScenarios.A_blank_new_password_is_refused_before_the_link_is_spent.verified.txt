# SqlOS behavior lock transcript
scenario: PublicPasswordResetScenarios.A_blank_new_password_is_refused_before_the_link_is_spent
profile: hosted

## 1. client: an empty new password is refused before the link is spent; this route answers every refused reset unhandled (#456), and 7.2.1 stored the empty password
> POST /sqlos/auth/password/reset
> Content-Type: application/json; charset=utf-8
>   {
>     "newPassword": "",
>     "token": "{link-token#1}"
>   }
< 204 No Content

## 2. client: the same link then sets a real password
> POST /sqlos/auth/password/reset
> Content-Type: application/json; charset=utf-8
>   {
>     "newPassword": "{password:alice-new}",
>     "token": "{link-token#1}"
>   }
< 500 Internal Server Error
< X-BehaviorLock-Unhandled-Exception: System.InvalidOperationException: Password reset token is invalid or expired.
